# Modüler Telegram Botu

Telegram grupları ve kanalları için hazır, özelleştirilebilir bot altyapısı.

## Modüller
- 🎁 **Çekiliş:** Butonla katılım, rastgele kazanan seçimi
- 🎫 **Destek:** Kullanıcılar talep açar, yönetici bot üzerinden yanıtlar
- 🛡️ **Grup yönetimi:** Hoş geldin mesajı, link engelleme, ban / atma
- 📊 **Aktivite:** En aktif üyeler ve grup istatistikleri


## Kurulum
1. `pip install -r requirements.txt`
2. `.env.example` dosyasını `.env` olarak kopyala ve doldur
3. `python bot.py`
